# 每局个性化协议

## 原则

采用“固定世界、定制旅程”：泡世界真相、核心碎片和通关主张不变；表现形式、人物入口和局部命运按玩家与随机种子组合。

不得基于敏感属性推断或定制。只使用玩家主动表达的叙事偏好、游戏风格和当前对话内容；缺省时直接随机选择，不要求填写画像。

## 可变维度

- 创造者人格：档案员、几何学家、悼亡者、沉默工程师。
- 镜面风格：冷静仪器、宗教圣像、故障全息、活体金属。
- 入口路线：针尖返航、公开审判、岩样实验、失踪者家属。
- 首个连接对象：幸存科学家、年轻执法者、科学院测量员、无名挖掘手。
- 题目顺序：从题库按先修条件重排。
- 描写密度：简洁、标准、文学；不得改变信息量与难度。
- 局部支线：证据由谁保存、谁获得声誉、谁承担代价、社会如何记忆镜谕。

## 定制约束

- 每局至少选择四个可变维度并写入 `profile`。
- 相同 `session_seed` 应产生相同配置，便于恢复。
- 不让某个皮肤额外泄露核心碎片。
- 不让定制角色替代历史锚点的因果作用；角色可以改变抵达锚点的路径。
- 开场只通过风格和场景体现定制，不展示内部画像或解释“为何这样定制”。
